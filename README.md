## Proyectos destacados

### Sistema de gestión para lubricentro

Aplicación Full-Stack orientada a la administración integral de un lubricentro.

Incluye:

* Gestión de clientes y vehículos.
* Órdenes de trabajo y servicios mecánicos.
* Inventario y movimientos de productos.
* Ventas, comprobantes y reportes.
* Gestión de empleados, roles y permisos.
* Autenticación mediante JWT y autorización RBAC.
* Formularios tipados y validaciones con React Hook Form y Zod.

**Tecnologías:** React, TypeScript, Material UI, TanStack Query, Node.js, Express, MongoDB y JWT.

`Repositorio privado o en desarrollo`

---

### Plataforma de licitaciones

Plataforma web modular para gestionar procesos de licitación, solicitudes de cuenta y acceso a distintos portales.

Incluye:

* APIs GraphQL con Apollo Server.
* Administración de usuarios, roles y permisos.
* Flujos de autenticación con múltiples tipos de token.
* Solicitudes de creación y validación de cuentas.
* Gestión segura de documentos.
* Integración entre portales públicos y privados.
* Validación de operaciones y control de acceso por contexto.

**Tecnologías:** React, Apollo Client, GraphQL, Node.js, Apollo Server, MongoDB, Mongoose y JWT.

`Repositorio privado`

---

### Demo de autenticación y RBAC

Proyecto enfocado en demostrar la implementación de autenticación y autorización basada en roles y permisos.

Incluye:

* Inicio de sesión mediante JWT.
* Usuarios, roles y permisos almacenados en MongoDB.
* Middleware de autorización.
* Seeds para datos iniciales.
* Documentación interactiva de endpoints.
* Interfaz web para probar permisos y accesos.

**Tecnologías:** React, Node.js, Express, MongoDB, JWT y Scalar.
