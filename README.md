## Sobre mí

Soy desarrollador **Full-Stack** con experiencia en la construcción de aplicaciones web, APIs y sistemas de gestión.

Trabajo principalmente con el ecosistema de **JavaScript y TypeScript**, desarrollando interfaces con React y servicios backend con Node.js, Express, Apollo Server y MongoDB.

Mis principales áreas de interés son:

* Arquitectura limpia y código mantenible.
* Autenticación, autorización y sistemas RBAC.
* Desarrollo de APIs REST y GraphQL.
* Automatización de procesos y CI/CD.
* Escalabilidad, seguridad y observabilidad.
* Experiencia de desarrollo y calidad de código.
